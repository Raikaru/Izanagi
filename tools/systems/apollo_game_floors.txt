# Void Quest chapters 1-3 (Go to the game: walk into the red target's CHECK, skip the prompts). On each floor: walk:shadow (the first Shadow; the planner Crosses through the battle), skipmsg, walk:goal (the stairs), press:up and Cross (the CHECK on the stairs). Needs the walker with the dungeon planner and walk:goal. Floor layouts follow the frame counter at the moment the floor is built, so the same script gives the same floors on the same build; `P4PC_GL_API=gl` on the Windows NVIDIA GPU (the GLES path crashed in the driver entering floor 4).
