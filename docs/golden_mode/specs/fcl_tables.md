# fclTable.bin (facility tables)

[Specs index](README.md) · [Containers](containers.md)

## Sources

- Measurement of build 10836033: `tools/golden_mode/layouts.py` (container, rows, row sizes, inferred
  fields, locale variance) and the Golden mode P4G.exe study's value comparison of the fusion and
  inheritance tables against the PS2 image tables (equality counts only).
- PS2 semantics: decomp `src/Event/Fcl/fclCombineMisc.c` (`FclSkillPickTier`, the inheritance weight

  (`skill.static_banks`, `fusion`).
- Public: Amicitia wiki "FTD" (container).

## Container

`init/fclTable.bin` is a PAK v2 member of `init_free.bin` holding 105 FTD tables
([Containers](containers.md)). 65 tables are locale-independent; 39 differ in every locale (text) and 1
in five.

## Records

### Specified tables (read by the fusion and inheritance code)

**`fclCombineSkillLimit.ftd`** — 9 rows x 2 bytes; PS2 `D_00641C20` (identical bytes in this build).

| Offset | Type | Field |
|---|---|---|
| 0 | s8 | minimum candidate-skill count for this tier |
| 1 | s8 | skills inherited at this tier |

The picker scans rows 8..0 and takes the first whose minimum is at most the candidate count; none gives 0.

**`fclCombineSkillAffinity.ftd`** — 14 rows x 38 bytes; PS2 `D_00641C40` (identical).

| Offset | Type | Field |
|---|---|---|
| 0 + 2e | s16 | base weight for element column `e` (0..18) |

Row = the persona's inheritance class (`PERSONA.TBL` block 0, +0x0A); column = the skill's element
(`SKILL.TBL` block 0), with 0xFF (passive/blank) read as column 18.

**`fclCombineSkillTargetLv.ftd`** — 624 rows x 1 byte; PS2 `D_00641E60` (576 rows).

| Offset | Type | Field |
|---|---|---|
| 0 | s8 | inheritance rate by Golden skill ID; 0 = never inherited |

Weight = base weight x 10 / rate. Rows follow the Golden skill domain: all 440 PS2 active rows are
equal; PS2 passive `p` is row `p + 0x20` (135 of 136 equal). Golden's file name says "target level"; the
PS2 code uses the values as rates, and that is the converted meaning.

**`fclCombineLift.ftd`** — 26 rows x 8 bytes; PS2 `D_006420A0` (23 rows, every one present verbatim).

| Offset | Type | Field |
|---|---|---|
| 0 | s32 | event flag that must be set |
| 4 | s16 | persona ID gated by the flag |
| 6 | s16 | gate bits (bit 0 is tested by the PS2 gate check; other bits copied) |

PS2 readers loop over exactly 23 rows (`0x17`); 26 rows needs the loop bound relocated with the table.

**`fclCombineTable_Normal.ftd`**, **`_Third_1.ftd`**, **`_Third_2.ftd`** — 28 rows x 28 bytes each.

| Offset | Type | Field |
|---|---|---|
| 0 + a | u8 | result arcana for (row arcana, column arcana `a`) |

PS2 has four 24 x 24 charts (normal pair, alternate pair, triple first, triple final). Golden's top-left
24 x 24 equals them: normal and triple first match `_Normal` (576/576), alternate matches 574/576,
triple final matches `_Third_2` (559/576). Rows/columns 24..27 are Golden's added arcana.

**Special recipes** — `fclCombineTable_NormalSP.ftd` (3 rows), `_ThirdSP` (1), `_Fourth` (4), `_Fifth`
(4), `_Sixth` (4), `_Twelfth` (1); 44-byte rows.

| Offset | Type | Field |
|---|---|---|
| 0x00 | u16 | result persona ID |
| 0x02 | u8[10] | zero |
| 0x0C | u16[12] | material persona IDs, unused slots 0 (the file's name gives the material count) |
| 0x24 | u8[8] | zero |

PS2 rows are 32 bytes: `u16 result`, 6 zero bytes, `s16 materials[8]` at +8, 8 zero bytes, in five
groups (11, 8, 6, 6, 6 physical rows; 16 non-empty). All 16 non-empty PS2 recipes appear in a Golden
row. The PS2 descriptor table (`D_00642F00`, pointer and count per group) is image-internal and is
generated by the image builder, not read from Golden.

## ID domains

Persona IDs are 0..255 and skill IDs follow the Golden skill domain ([Battle tables](battle_tables.md#id-domains)).
Arcana indices are 0..27 (PS2 0..23).

## Invariants and refusals

- Exactly the rows and row sizes listed here and in the catalogue; any other build is refused.
- `fclCombineSkillTargetLv` has as many rows as `SKILL.TBL` block 0.
- Chart values are arcana indices below the chart's row count, or the chart's "none" value.
- Recipe materials and results are persona IDs; a recipe has at least two materials.

## PS2 differences

PS2 keeps these fusion and inheritance tables in its executable image (`0x00641C20`..`0x00642F28`);
Golden keeps them in this pack, wider: 624 skill rates, 26 gate rows, 28-arcana charts, 44-byte recipe
rows with up to 12 materials.
